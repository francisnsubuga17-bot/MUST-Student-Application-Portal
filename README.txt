MUST APPLY — Student Portal UI Prototype

FILES
- index.html: semantic HTML5 structure, both authentication forms, and small demo-only JavaScript for switching views and displaying status messages.
- styles.css: responsive styling, design tokens, CSS-only campus illustration, focus states, and mobile layout.

RUN
1. Keep index.html and styles.css in the same folder.
2. Open index.html in a modern browser.
3. Select “Create an account” or “Sign in” to switch interfaces.

IMPORTANT
This is a front-end prototype. Form submissions are validated in the browser but do not create accounts, store passwords, or authenticate students. A production system requires a secure server-side API, password hashing, email verification, secure sessions, CSRF protections, rate limiting, and an approved password recovery flow.
